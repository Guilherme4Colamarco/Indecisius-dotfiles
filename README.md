## 📢 Aviso

Este setup foi oficialmente **abandonado** em julho de 2026.

Ele está arquivado aqui apenas como referência histórica, mas continuará disponível para quem quiser baixar, modificar, estudar ou testar por conta própria. Não espere manutenção, correções ou suporte.

### O que mudou

O desenvolvimento deste rice foi movido para um novo projeto:

**[kamalen-shell](https://github.com/Guilherme4Colamarco/kamalen-shell)** — um fork completo do [Alphonso](https://github.com/ernestoCruz05/alphonso) (QuickShell + Mango-ext)

O kamalen substitui todo o stack deste repositório:

| Componente | Indecisius (antigo) | **kamalen (novo)** |
|------------|:-----------------:|:-----------------:|
| **Shell/Bar** | Waybar + Wofi | **QuickShell** (QML panels) |
| **WM** | MangoWM | **Mango-ext** |
| **Cores** | matugen | **Iris** (extração própria) |
| **Notificações** | Mako | NotificationPopup nativo |
| **Power menu** | wlogout | PowerMenu nativo |
| **Layout menu** | Wofi script | LayoutMenu nativo |
| **Clipboard** | cliphist + Wofi | ClipboardMenu nativo |
| **Visualizer** | Cava | Cava integrado no Dashboard |
| **Wallpaper** | awww + waypaper | Wallpaper selector nativo |

---

## 📜 Histórico

Este repo documenta a fase do setup que usava:

- **MangoWM** com Waybar + Wofi + matugen
- Um bash script de instalação modular
- Inspiração no [cybr-core](https://github.com/cybrcore) visual style

Tudo isso foi superado pelo **kamalen** — uma experiência Wayland muito mais integrada, responsiva e visualmente coesa.
